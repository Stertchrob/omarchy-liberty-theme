# Liberty

A dark red, white, and blue theme for Omarchy.

## Install

```bash
omarchy theme install https://github.com/Stertchrob/omarchy-liberty-theme
```

## Wallpapers

Wallpapers live in `backgrounds/`. Omarchy uses them in filename order. `1-eagle.jpg` is the first.

Add more as jpg, png, or webp, with names that sort after the ones already there (`2-...`, `3-...`). Then update a machine that already has the theme:

```bash
git -C ~/.config/omarchy/themes/liberty pull
omarchy theme set liberty
```
